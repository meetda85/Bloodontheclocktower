# Audios propios

Deja aquí los ficheros de sonido que quieras usar para los efectos (`.mp3`, `.ogg`, `.wav`…)
y escribe la ruta en *Ajustes → Opciones*, por ejemplo:

```
audio/fin-del-dia.mp3
```

Así el sonido viaja con la aplicación y funciona en todas las tablets, en vez de quedarse
guardado solo en el navegador de una. Usa audio del que tengas derechos (grabaciones propias
o con licencia libre).
